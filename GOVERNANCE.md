# Governance

Rubric Studio Open is maintained by the AuraOne Open source maintainers.

## Maintainer responsibilities

- Review pull requests for product boundary, privacy, security, and rubric-spec
  compatibility.
- Keep the folder-based project format stable and documented.
- Avoid moving hosted, workforce, payments, or multi-tenant Cloud workflows into
  the OSS app.
- Prefer interoperable exports over vendor lock-in.

## Decision process

Small implementation decisions are handled in pull requests. Format changes,
new engine integrations, and distribution/security changes require an RFC or a
tracked maintainer decision before merge.
